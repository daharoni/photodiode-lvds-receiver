# Photodiode LVDS Receiver

Optical receiver module for the next-generation wireless UCLA Miniscope data
uplink. It succeeds the receiver used with the Miniscope Zero link
(bioRxiv 10.64898/2026.09.05.745822). Target: 50 Mbps line rate (8b/10b,
40 Mbps payload, UI = 20 ns).

Signal chain: silicon APD (primary Hamamatsu S12023-10; FDS010 PIN only as a bench
fallback) on a programmable, temperature-compensated 100-220 V bias
(APD_BIAS) -> OPA857 transimpedance
amplifier -> AC coupling -> OPA855 fixed-gain post-amplifier -> TLV3605
comparator sliced at the AC baseline, LVDS output -> one LVDS pair to an ECP5
FPGA (ULX3S first), which does clock recovery, 8b/10b decode and redundant-lane
merging. An on-module ESP32-C6 trims the APD bias and TIA gain slowly over a
CAN link and reports the module identity. The architecture is analog-first by
decision; see `docs/decision-log.md` (entries 11 and 12).

Each module has one 24-pin USB-C receptacle (decision 14) that carries 5 V, the LVDS
pair duplicated on both SuperSpeed TX pairs, CAN on both RX pairs and USB D+/D- for
programming and self-test from a laptop with no FPGA attached; a scope header and
test points serve the bench. It is intended for a shielded aluminum housing with a
swappable optical bandpass filter.

## Status

Pre-G1, layout in progress (2026-10-12). Rev A schematic is complete (six
hierarchical sheets, 221 components, 144 nets, ERC 0 errors / 0 warnings, spec
revision 4 after decision 14); the generators are frozen and edits go through the
KiCad GUI. The PCB is a 6-layer JLCPCB JLC06161H-3313 board on a 75 x 50 mm
placeholder outline with all 221 footprints placed by the first-pass placement
script; routing is complete (0 unconnected, DRC 11 items accepted in writing in the review README). No hardware, no measurements; three ngspice simulations
with TI models exist (`docs/simulation/README.md`, SIMULATED, not VERIFIED).
Component choices are provisional until the bring-up gates in
`docs/bringup/gates.md` pass. The largest open risks are the APD bias supply, the
USB-C cable and foreign-host behaviour (decision 14), OPA857 behavior at 6 pF,
post-amp clipping and comparator noise at small overdrive, and the firmware
range-control loop. Per-sheet as-built notes with datasheet citations are in
`docs/schematic/`; `docs/receiver-guide.html` is the derived field guide.

## Opening the KiCad project

Requires KiCad 10 and the lab component library from
`~/Projects/kicad-lab-library`, installed with that repo's install script so
that `${AHARONI_LAB_KICAD_LIB}` resolves. Then open
`hardware/pcb/receiver-module/receiver-module.kicad_pro`. The sheets were
generated by the scripts in `hardware/pcb/receiver-module/gen/` using
`tools/kicad_sch`; the generators are frozen since 2026-10-09 (`gen/FROZEN`,
layout started), so schematic changes go through the KiCad GUI with the spec and
as-built notes in `docs/schematic/` updated by hand.
New parts are added to the lab library by PR, not as project-local symbols.
