# Photodiode LVDS Receiver

Optical receiver module for the next-generation wireless UCLA Miniscope data
uplink. It succeeds the receiver used with the Miniscope Zero link
(bioRxiv 10.64898/2026.09.05.745822). Target: 50 Mbps line rate (8b/10b,
40 Mbps payload, UI = 20 ns).

Signal chain: silicon APD (primary Hamamatsu S12023-10; FDS010 PIN only as a bench
fallback) on a programmable, temperature-compensated 100-220 V bias
(APD_BIAS) -> OPA857 transimpedance
amplifier -> AC coupling -> OPA855 fixed-gain post-amplifier -> TLV3605
comparator sliced at the AC baseline, LVDS output -> one LVDS pair to an ECP5
FPGA (ULX3S first), which does clock recovery, 8b/10b decode and redundant-lane
merging. An on-module ESP32-C6 trims the APD bias and TIA gain slowly over a
CAN link and reports the module identity. The architecture is analog-first by
decision; see `docs/decision-log.md` (entries 11 and 12).

The module exposes 5 V power, ground, one LVDS pair, a CAN pair and debug pads. It is
intended for a shielded aluminum housing with a swappable optical bandpass
filter.

## Status

Pre-G1. Rev A schematic is populated (seven hierarchical sheets, about 210
parts, project ERC 0 errors as of 2026-10-08); no PCB layout, no hardware, no
measurements yet. Component choices are provisional until the bring-up gates in
`docs/bringup/gates.md` pass. The APD bias supply, the fast high/low detector,
the AGC loop (anti-windup, VG bound) and OPA857 behavior at 6 pF are the largest
open risks. Per-sheet as-built notes with datasheet citations are in
`docs/schematic/`.

## Opening the KiCad project

Requires KiCad 10 and the lab component library from
`~/Projects/kicad-lab-library`, installed with that repo's install script so
that `${AHARONI_LAB_KICAD_LIB}` resolves. Then open
`hardware/pcb/receiver-module/receiver-module.kicad_pro`. The sheets are
generated by the scripts in `hardware/pcb/receiver-module/gen/` using
`tools/kicad_sch`; edit the generator, not the .kicad_sch, while the design is
still being iterated this way (or stop regenerating a sheet once it is hand-edited in KiCad).
New parts are added to the lab library by PR, not as project-local symbols.
