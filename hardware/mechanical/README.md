# Mechanical

Enclosure, optical filter holder and mounting are TBD. The intent is a shielded aluminum housing (the module sits in a 6.63 MHz quasistatic cavity resonance wireless-power field) with a swappable optical bandpass filter window so one module serves both the 630 nm red and 765 nm NIR emitters. There are no size constraints now; smaller is better, and the board will be condensed after electrical validation. Detector-to-window geometry depends on the detector choice (open item).
